# Git

- Never create branches, worktrees or commits automatically. ONly do so when the user explicitly asks for that specific action in the current request.
- Leave changes uncommitted in the work tree on the current branch and let the user decide how and what to commit

# Development Data Policy

- This is a development project; backwards compatibility is not required, and its data has no value.
- Never backfill data, migrate data, or work to preserve existing rows or columns. Data loss is acceptable.
